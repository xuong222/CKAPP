# CH32 多传感器设备寄存器说明

## 1. 地址和编码规则

- 文档地址 40001 对应 Modbus PDU 零基地址 `0x0000`；换算公式为 `协议地址 = 文档地址 - 40001`。
- 每个寄存器在线路上都是一个 16 位原始字，寄存器数据按大端顺序传输。
- CRC16 在完整 RTU 帧尾部按低字节、高字节顺序传输。
- 地址、枚举代码、布尔值、位掩码和命令按 UInt16 语义解释。
- 测量值、阈值、回差和补偿按各自定义使用 Int16 二进制补码；不得使用全局统一 int16 规则替代逐项定义。
- `RO` 表示参数页只读，`RW` 表示允许写入，`专用` 表示必须走地址、波特率或恢复出厂独立流程。

## 3. 报警位映射

40010 和 40023 的低六位使用同一通道顺序：

| 位 | 掩码 | 通道 |
|---:|:---:|---|
| bit0 | 0x0001 | 温度 |
| bit1 | 0x0002 | 烟雾 |
| bit2 | 0x0004 | PM2.5 |
| bit3 | 0x0008 | CO |
| bit4 | 0x0010 | CO2 |
| bit5 | 0x0020 | SO2 |

40010 表示当前具体报警项；40023 表示各报警通道是否启用。“已启用”不等于“正在报警”。超过低六位的状态在读取时保留诊断，但写入 40023 时必须拒绝。

## 4. 功能码使用建议

- 0x03：读取任意合法连续范围，单次数量 1～125；
- 0x06：写单个寄存器，适合专用配置或单值调试；
- 0x10：写连续普通参数组，单次数量 1～123；
- 参数页只允许写表中明确标为 RW 的普通参数；
- 40001、40002、40036 必须走独立安全流程；
- 只读测量值、报警状态和实测值不得由参数页写入。

## 5. 特殊注意事项

### 5.1 烟雾单位

烟雾寄存器使用 MQ2 线性单位。当前固件没有提供经过标定的 ppm 转换曲线，因此界面和文档不得把它标成 ppm。

### 5.2 回差

40012、40014、40016、40018、40020、40022 使用有符号 Int16，合法值必须 `<= 0`。负值在线路上按 16 位二进制补码编码。

### 5.3 地址和波特率切换

设备可能在发送写响应后切换地址或波特率。上位机必须先验证旧配置下的回显，再更新本地连接。响应丢失时状态为 ConfigurationUncertain，不得自动假定写入失败或成功。

### 5.4 恢复出厂

40036 不是持久状态寄存器。读取恒为 0，只有写入原始值 1 才触发命令。执行后本地配置恢复为从站地址 1、9600-8-N-1。
